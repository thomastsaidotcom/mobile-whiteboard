# Mobile Whiteboard

Mobile Whiteboard lets a person read and edit Whiteboard review content from a phone.

## Language

**Mobile Whiteboard**:
The phone companion to Whiteboard for reading reviews and editing their content.
_Avoid_: Mobile IDE, remote desktop

**Review**:
A Whiteboard explanation of code changes against a selected source target, with its authored content and saved versions.
_Avoid_: Chat, coding session

**Review content**:
The authored explanation within a Review, including text and diagrams, distinct from the source code it describes.
_Avoid_: Source code, repository files

**Headless authoring**:
Creating and editing a Review without installing or running the desktop application, including from a CI job.
